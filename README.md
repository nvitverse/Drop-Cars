# Drop Cars - Complete Ecosystem Repository

This repository contains the complete production-grade source code for the **Drop Cars** platform.

## Repository Structure

```
├── admin-panel/        # Drop Cars Admin Dashboard & Mobile Application (React Native / Expo)
├── backend/            # High-Performance FastAPI Python Backend Server & APIs
├── customer-app/       # Drop Cars Customer Mobile Booking App (React Native / Expo)
├── driver-app/         # Drop Cars Vendor & Driver Partner App (React Native / Expo)
├── website/            # Drop Cars Official Booking Website & Landing Pages
└── README.md           # Repository Documentation
```

## Modules Overview

### 1. 📱 Customer App (`customer-app/`)
- Expo / React Native customer application.
- Real-time ride booking, one-way/round-trip tariffs, instant estimates, OTP verification, live tracking.

### 2. 🚖 Driver & Vendor App (`driver-app/`)
- Vendor and driver dispatch mobile app.
- Tour bidding, live ride dispatch feeds, instant notifications, trip start/end OTPs, wallet & payout management.

### 3. 🖥️ Admin Panel (`admin-panel/`)
- Centralized operations management hub.
- Live order dispatch, driver approvals, KYC verification, revenue analytics, tariff customization, CRM, emergency bidding.

### 4. ⚙️ Backend API (`backend/`)
- FastAPI Python REST API backend.
- PostgreSQL database integration, Firebase push notifications, Maps API pool, automated rate calculations, secure JWT auth.

### 5. 🌐 Website (`website/`)
- Official customer-facing web portal.
- Fast booking engine, route directory, city landing pages, SEO-optimized content.
